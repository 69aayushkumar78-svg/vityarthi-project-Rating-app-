# Product Rating System (CLI)

A lightweight, terminal-based Python application that allows an Administrator to manage products and enables Users to rate products across multiple criteria without requiring a Graphical User Interface (GUI).

---

## 🛠️ Key Features

- **Dynamic Admin Setup & Security:** Set custom Admin credentials on the first run, with the ability to update them anytime from the Admin Dashboard.
- **Multi-Criteria User Ratings:** Rate products on 1–5 star scales across three distinct metrics:
  - Worth of Money
  - Product Quality
  - Customer Support
- **Admin Dashboard:**
  - Add new products to the catalog.
  - View overall rating averages and detailed breakdown per user submission.
  - Update Admin credentials.
- **Data Persistence:** Automatically stores and reads all data using a local `app_data.json` file.
